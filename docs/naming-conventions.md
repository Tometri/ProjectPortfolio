# Naming Conventions

Use these standards for new content. Existing content can be migrated gradually.

## Folders

- Prefer `kebab-case` (`module-four`, `hash-calculation-one`).
- Avoid spaces in new folder names.
- Keep course codes and terms consistent (`IST2263`, `Spring2026`).

## Files

- Markdown docs: `README.md`, `notes.md`, `summary.md`.
- Screenshots: `topic-01.png`, `topic-02.png`.
- Scripts: meaningful names with extension (`user-audit.ps1`, `bill-split-calculator.py`).

## Course Layout Pattern

Use this pattern for new course modules:

```text
CourseFolder/
  README.md
  module-01/
  module-02/
  module-03/
```

## Documentation Pattern

Each major folder should include a `README.md` with:

1. Objective
2. Tools used
3. Steps performed
4. Evidence or screenshots
5. Key takeaways
