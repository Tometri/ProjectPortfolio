# Structure Roadmap

This roadmap tracks practical cleanup steps to improve maintainability and presentation.

## Phase 1: Completed

1. Added central navigation files in `docs/`.
2. Reworked root `README.md` with valid links.
3. Added top-level `README.md` files for major sections.
4. Added `.gitignore`.

## Phase 2: Recommended Next

1. Add `README.md` inside each course folder with module links.
2. Convert key `.odt/.docx` deliverables into concise Markdown summaries.
3. Add a dedicated `evidence/` folder per module for screenshots and media.
4. Normalize typo/inconsistent names, starting with:
   - `Moule Four` -> `Module Four` (or `module-04`)
   - `Module One`/`ModuleTwo` style mismatches

## Phase 3: Portfolio Quality

1. Promote 3 to 5 strongest labs into `labs/<lab-name>/README.md`.
2. Include reproducible steps and commands for each highlighted project.
3. Add a lightweight changelog or monthly progress log.
