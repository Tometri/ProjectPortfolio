# Resume

Resume documents and versions are stored here.

## Organization

1. Older (pre-name-change) versions are archived in `archive/` — they are kept for record, not for sending out.
2. The current resume is the McDuff version kept in Dossier (`Documents/Resume/Archive/`); this folder holds only the archive copies and the HTML version (`resume.html`).
3. File naming for new versions: `mcduff-resume-YYYY-MM`.
